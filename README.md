# Python To-Do List Application

## Overview
This project is a basic command-line To-Do List application developed using Python. It provides users with a simple way to manage their daily tasks through a menu-based interface. Users can add new tasks, display existing tasks, remove selected tasks, and close the application when finished.

## Features
- Add new tasks to the task list
- Display all saved tasks with task numbers
- Remove a task by selecting its number
- Exit the application safely
- Validate user input to handle incorrect menu options and task numbers

## Technologies / Tools Used
- Python 3
- Built-in Python libraries
- Standard Python libraries (no external dependencies)
- Command-line interface (CLI) for interaction

## Installation & Setup
1. Ensure Python 3 is installed on your system. You can download it from https://www.python.org/downloads/.
2. Save the Python script (e.g., `todo_list.py`) containing the program code to your local machine.
3. Open a terminal or command prompt.
4. Navigate to the directory where the script is saved.
5. Run the program by executing:
6. ## Instructions for Running the Project
7. Upon running the script, a menu with options will be displayed.
8. Enter the number corresponding to your desired action:
- `1` to add a task
- `2` to view all tasks
- `3` to delete a task
- `4` to exit
3. Follow on-screen prompts for each action.
4. To delete tasks, enter the task number as shown in the task list.
5. To exit, choose option `4`.

## Instructions for Testing
- Test adding tasks by selecting option `1` and entering various task descriptions.
- Test viewing tasks by choosing option `2` and confirming the displayed tasks match the added ones.
- Test deleting tasks by selecting option `3` and entering valid and invalid task numbers to verify error handling.
- Test exiting the program via option `4`.
- For invalid inputs (like letters or numbers out of range), verify the program displays an error message and re-displays the menu without crashing.
